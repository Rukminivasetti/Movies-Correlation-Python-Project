# Movies Correlation Analysis – Python

## Project Overview

This project analyzes a movies dataset using Python to explore relationships and correlations between movie features such as budget, gross revenue, votes, score, and other attributes.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Explored the structure of the dataset
- Checked data types
- Identified missing values
- Checked for duplicate records
- Analyzed unique values
- Generated descriptive statistics
- Cleaned and prepared the data
- Explored relationships between movie features
- Created visualizations to understand correlations

## Dataset

The dataset contains movie information including:

- Movie name
- Rating
- Genre
- Release year
- Score
- Votes
- Budget
- Gross revenue
- Runtime
- Director
- Writer
- Star
- Country
- Production company

- Data cleaning

- Data visualization
- Python-based exploratory data analysis

This project demonstrates how Python can be used to explore a real-world dataset, identify patterns between variables, and communicate findings through data visualization.
